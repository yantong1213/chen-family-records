# 陳家紀錄

懷念 陳双春 先生（1938–2026）的照片與影片紀念網站。純靜態網頁。

## 檔案說明

- `index.html`：主頁（紀念頁）
- `family.html`：族譜
- `js/data.js`：每張照片與影片的說明文字（可直接修改）
- `js/gate.js`：前端密碼閘門（見下方）
- `photos/`、`thumbs/`、`videos/`、`posters/`：媒體檔案

## 家人密碼閘門（輕量、非高安全性）

開啟網站時會先出現密碼提示：「家人專用｜請輸入密碼」。輸入正確後，同一瀏覽器分頁／工作階段內會記住（`sessionStorage`），重新整理不必再輸入；關閉分頁後需再輸入。

**密碼：** 見 `js/gate.js`

**如何更改密碼：** 編輯 `js/gate.js` 最上方的常數：

```js
var PASSWORD = '…';
```

改成你想要的字串即可。

> **注意：** 這不是高安全性保護。靜態網站（含 GitHub Pages）沒有伺服器端驗證時，密碼會寫在前端的 JavaScript 裡，懂得看原始碼的人都能找到。此閘門的用途是擋住不經意的訪客，不適合保護真正機密的資料。
